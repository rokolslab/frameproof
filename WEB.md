# Запуск веб-интерфейса

Windows-first. Папка приложения может содержать пробелы и `+`.

```powershell
git clone https://github.com/rokolslab/frameproof.git
cd frameproof
.\Start-Frameproof.ps1 -MediaRoot 'D:\Видео'
```

Без MediaRoot можно загружать видео и субтитры через браузер. Скрипт использует
`.venv`, а при её отсутствии создаёт её и устанавливает зависимости web.
Если Python отсутствует, выводит ссылку на официальный установщик.
FFmpeg, OCR и Whisper проверяются в разделе «Готовность»; там есть команды и ссылки.

На Windows также доступны «Установить» / «Настроить». После подтверждения запускается
PowerShell с фиксированным набором пакетов. WinGet использует тихий режим и при
необходимости вызывает UAC на хосте; Python-пакеты устанавливаются только в venv
приложения. Подтверждение включает согласие с лицензиями пакета и источника.
Драйверы и системная политика выполнения PowerShell не меняются.
Во время установки недоступны новый анализ видео и завершение через интерфейс.
Не закрывай процесс приложения вручную: установка может продолжиться отдельно.
Журнал доступен в «Готовности». Повторная проверка не запускает установку заново.

После установки приложение перечитывает PATH системы и пользователя. Путь к
Tesseract при необходимости дописывается в пользовательский PATH без `setx` и
удаления существующих записей. Языки rus/eng скачиваются из официального tessdata_fast
4.1.0 в `%LOCALAPPDATA%\Frameproof\tessdata`; OCR приложения использует эту папку.
Поэтому обычный `tesseract --list-langs` может показывать другой набор языков;
проверка в интерфейсе учитывает папку приложения.

Ручная установка и запуск (Windows):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install '.[web]'
.\.venv\Scripts\python.exe -m frameproof web --media-root 'D:\Видео'
```

Linux/macOS (архитектурно предусмотрено, требуется отдельная живая проверка):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install '.[web]'
.venv/bin/python -m frameproof web --media-root /path/to/videos
```

Адрес: http://127.0.0.1:8765. В конце работы «Завершить приложение» или Ctrl+C.
Автозапуска нет. Закрытие вкладки не останавливает сервер. После задачи процесс
распознавания завершается: модель освобождается, результаты остаются на диске.

## Файлы и результаты

### Прочитать текст лекции или совещания

1. Открой «Обработки» → нужную запись → «Открыть обработку».
2. Интерфейс перейдёт к «Текст видео»: речь показана абзацами с тайм-кодами.
   Для длинных записей используй «Следующие реплики» / «Предыдущие реплики».
3. «Копировать весь текст» переносит все реплики в буфер обмена. «Скачать TXT»
   даёт обычный текст для чтения/агента, Markdown — текст с тайм-кодами,
   SRT — субтитры. Скачивается вся расшифровка, не только текущая страница.

Отдельно сохранять результат не нужно. Сразу после распознавания речи сохраняются
`segments.jsonl`, `transcript.txt`, `transcript.md`, `transcript.srt` в
`.web-data/jobs/<идентификатор>/index/` при запуске через Start-Frameproof.ps1.
Путь виден рядом с текстом. Закрытие вкладки или приложения не удаляет файлы.
После перезапуска с той же папкой данных история и расшифровки доступны снова.
Если кадры или OCR завершатся с ошибкой, уже сохранённый текст остаётся доступным.
Ненужную завершённую, ошибочную, остановленную или прерванную обработку можно удалить
из списка. Подтверждение удаляет её индекс, расшифровку, кадры и журнал с хоста;
исходное видео не затрагивается. Идущую обработку сначала останови и дождись её конца.

Ранее созданные обработки также читаются и скачиваются из `segments.jsonl`,
повторное распознавание не нужно. Для них TXT/Markdown/SRT формируются при скачивании.
Внешний готовый индекс при чтении не изменяется. Если речь была отключена или
движок не вернул текст, интерфейс объясняет это и предлагает проверить журнал.
Конспект, редактирование текста и автоматическое разделение участников пока не
реализованы. Расшифровка может содержать ошибки распознавания.

### Другие возможности

- «На компьютере с браузером»: загрузка на хост, максимум 20 ГиБ за файл.
- «На диске хоста»: выбор без копирования в пределах `--media-root`.
- «По ссылке»: скачивание выполняет хост. Для cookies и подписанных URL пока CLI.
- Субтитры .srt/.vtt/.json3 заменяют локальную расшифровку.
- Режимы качества управляют кадрами, а не размером модели речи.
- «Обработки»: история, журнал, отмена, поиск, открытие кадров и проверка меток.
- Прогресс-бар показывает текущий этап: скачивание, речь, анализ, кадры, OCR,
  сохранение. Процент извлечения считается по обработанным кадрам и относится
  только к этому этапу. Для речи/OCR без счётчика показан неопределённый индикатор.
  Итоговые 100% появляются после успешного завершения процесса, не при ошибке/отмене.
- Старый индекс открывается из разрешённой папки с index.json и frames.jsonl.
- Поиск и список метаданных кадров не отмечают кадры просмотренными; выдача
  изображения отмечает их в served.jsonl. Просмотр человеком не доказывает,
  что изображение было передано внешнему AI-агенту.

Установленный Whisper запускается Python-интерпретатором приложения, без требования
активации venv. MLX продолжает использоваться на Apple Silicon. Faster-whisper
не включён без измерений. Модели впервые могут скачиваться из сети.

## Удалённый браузер

Запусти приложение вручную на хосте с `--no-browser`. На клиенте открой туннель:

```powershell
ssh -N -L 8765:127.0.0.1:8765 user@host
```

Затем открой http://127.0.0.1:8765 в браузере клиента. Оба порта должны совпадать
с портом приложения. SSH должен быть отдельно настроен на хосте. Прямой HTTP-доступ
по LAN-IP не включён; туннель обеспечивает аутентификацию и шифрование.

## Проверка

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m pip install '.[web,dev]'
.\.venv\Scripts\python.exe -m pytest -q
node --check frameproof/assets/web/app.js
node tests/test_transcript_ui.cjs
```

Real FFmpeg tests требуют ffmpeg/ffprobe в PATH; иначе они явно пропускаются.
Проверки API используют синтетические данные, не реальные пользовательские видео.
