## Границы подтверждённой готовности

- Живая обработка проверена с готовыми субтитрами, не с установленной моделью речи.
- NVIDIA/CUDA, Apple Silicon/MLX, Linux/macOS, OCR-движки и реальный SSH-туннель
  требуют отдельной аппаратной приёмки. Unit-тесты не заменяют её.
- URL-сценарий покрыт проверками параметров и существующими тестами загрузчика;
  скачивание с внешнего видеосервиса в этой приёмке не выполнялось.
- Faster-whisper не интегрирован. Прямой HTTP-доступ по LAN-IP не включён;
  удалённое использование документировано через SSH-туннель.
- Установка из интерфейса Windows добавлена по запросу пользователя. Разрешены
  только фиксированные компоненты; произвольные команды через HTTP запрещены.
  Проверены синтаксис всех PowerShell-сценариев, настоящий безопасный тестовый
  процесс, успех/ошибка/повторный запрос, API-подтверждение и CSRF, блокировка
  видео/завершения, сохранение PATH при обновлении окружения, проверка языков.
  В браузере проверены подтверждение/отказ, выполнение, успех, ошибка и журнал
  на стенде `tests/serve_install_ui.py`, который не устанавливает пакеты и
  не записывает пользовательский PATH. Проверена ширина 390 px без переполнения.
  Реальная установка через WinGet, изменение постоянного PATH и UAC в этой
  проверке не выполнялись: это оставшаяся проверка на хосте пользователя.
- Тестовые медиа, данные обработок и portable FFmpeg находятся в игнорируемых
  Git каталогах `test-media`, `.web-data`, `tools`. Автозапуск не настроен.

Инструкция: [WEB.md](WEB.md). Полная аппаратная приёмка пока не завершена.
